# YOLOv8 Object Detection Web Service

A full-stack web application for object detection using YOLOv8. This project allows users to upload images through a web interface and receive object detection results with bounding boxes, class labels, and confidence scores.

## Features

- Object detection using YOLOv8
- Custom model training support
- Frontend for image upload and result display
- Backend API for model inference
- Fast and accurate predictions

## Tech Stack

- Python
- YOLOv8
- PyTorch
- Flask / FastAPI
- HTML
- CSS
- JavaScript

## Project Workflow

1. Prepare and annotate the dataset in YOLO format.
2. Train the YOLOv8 model on the custom dataset.
3. Build the backend service for inference.
4. Create the frontend for user interaction.
5. Upload images and display object detection results.
